# Subsurface Pore Pressure & Overburden Stress Calculator

A computational Python tool designed to model subsurface hydrostatic pressure, formation fluid pressure, and overburden stress profiles along depth trajectories.

## Features
- Calculates hydrostatic fluid head pressure based on dynamic depth input.
- Computes formation fluid pressure from equivalent mud weight parameters.
- Models overburden stress profile using lithostatic gradients.
- Automatically plots and exports depth-versus-pressure logs.
